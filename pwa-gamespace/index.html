Установка вручную На Android: откройте меню браузера и выберите «Установить приложение». На iPhone и iPad: откройте «Поделиться» и выберите «На экран Домой». ДЕМО-САЙТ ВНУТРИ

Можно начать без своего архива

Откройте GameSpace со значка или во вкладке — встроенное демо автоматически появится готовым в списке «Мои архивы». При первом запуске демо подготовится автоматически; затем каталог игр будет доступен без сети.

Демо можно оставить в приложении: для своей работы загрузите собственный архив. Переносить игры и материалы из демо в него нельзя.

Мои архивы

Встроенное демо готовится автоматически. Также можно добавить свой архив с устройства.

    Как управлять архивами

    Обновить — добавить и заменить файлы без удаления остальных. Заменить — полностью заменить содержимое архива. У каждого архива свои сохранения localStorage и результаты проверки совместимости.

    Открывайте только проверенные архивы: их JavaScript получает localStorage в доверенном режиме. Переносить материалы встроенного демо в свой архив нельзя.

    Просмотр доступен в одном окне GameSpace. Перед переключением, обновлением или удалением закройте просмотр в другом окне.

    Квота не резервирует место на устройстве. Храните исходный архив отдельно: повторный импорт восстановит сайт, но не созданные в играх сохранения.

    У каждого архива свой localStorage.

    Как переключаются сохранения

    При первом включении общим станет текущий набор. При повторном включении вернётся сохранённый общий набор. Выключение возвращает индивидуальные сохранения без объединения данных. Новые архивы начинают с пустого индивидуального набора.

    Другие хранилища игр остаются общими: IndexedDB, cookies, Cache Storage и файлы, которые игры создают через OPFS. sessionStorage зависит от окна браузера и не переключается по архивам. Настройки GameSpace и квота браузера общие.

    Проверка совместимости

    1. Запуск приложения: Установите PWA и откройте её значок. Локальный просмотр во вкладке не подтверждает установку.
    2. Импорт архива: Демо устанавливается автоматически при первом запуске. Если импорт уже выполнен, откройте витрину и игру. Для повторной проверки демо нажмите «Восстановить демо»; для своего архива выполните полную установку.
    3. Загрузка витрины: Нажмите «К играм» и дождитесь появления витрины игр.
    4. Переход в игру: Откройте одну из игр из витрины внутри GameSpace. Проходить игру для проверки не требуется.
