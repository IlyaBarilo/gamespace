# Проверка диагностики PWA

Автоматические тесты `node --test` проверяют отчёты, копирование/отмену отправки,
ограничения журналов, ошибки хранения отчёта и передачу исключений Worker.
ZIP проверяется через настоящий распаковщик с подменой OPFS: успешный импорт,
отсутствующий index.html, неверный заголовок, квота, отказ создания/записи
и завершения записи файла. Отдельно проверен отказ чтения сведений о браузере.
Тесты не изменяют пользовательские архивы и не требуют браузера.

## На тестовом устройстве или в отдельном профиле браузера

Не удаляйте рабочий сайт и не заполняйте рабочее хранилище ради проверки.
Используйте отдельные небольшие тестовые ZIP/7z.

1. Установите корректный ZIP и 7z с index.html, сначала без демо, затем после
   демо. Установка должна завершаться как прежде.
2. Выберите повреждённый архив или архив без index.html. Убедитесь, что отчёт
   содержит версию PWA, исходный этап, имя архива и техническую причину. Для
   отсутствующего index.html ожидается `GS-INDEX-CHECK`.
3. Для ошибки 7z проверьте сообщения обработчика и стек Worker. При сбое
   очистки первоначальный этап не должен заменяться этапом удаления файлов.
4. Нажмите «Копировать», вставьте отчёт в черновик. При запрете Clipboard API
   должна появиться инструкция ручного копирования и выделиться текст.
5. Нажмите «Отправить». В поддерживаемом браузере должно открыться системное
   меню; отправляется только текст, без самого архива. Отмените действие:
   исходный отчёт должен сохраниться. В неподдерживаемом браузере предлагается
   скопировать отчёт вручную.
6. Закройте окно, перезапустите PWA и откройте «Последняя ошибка». Номер, время
   и текст должны совпадать. Успешный повторный импорт не удаляет отчёт.
7. Проверьте узкий экран и крупный шрифт: текст прокручивается, кнопки доступны,
   Tab остаётся внутри диалога, Escape закрывает его и возвращает фокус.
8. При ошибке запуска страницы установки отчёт также должен открываться;
   повторно он доступен по кнопке внизу страницы.
9. При недоступном localStorage новый отчёт остаётся доступен до закрытия
   приложения и показывает предупреждение о невозможности сохранения.

Изменения касаются оболочки PWA; неизменяемый `sw-runtime-v1.js` не изменяется.
